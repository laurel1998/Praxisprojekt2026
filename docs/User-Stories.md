# User Stories

## Information

Die folgenden User Stories konkretisieren die funktionalen Anforderungen des MVP. Sie werden nach dem Prinzip der [MoSCoW-Priorisierung](https://www.agile-heroes.com/de/magazine/moscow-priorisierung/) kategorisiert. Aktuell werden zunächst ausschließlich die Anforderungen der Nutzer:innen betrachtet. Weitere Stakeholder werden für den MVP nicht gesondert berücksichtigt.

### MUST

- U1: Als Nutzer:in möchte ich erkennen können, ob eine Kommentarinteraktion unauffällig oder auffällig ist, damit ich mögliche automatisierte Interaktionen besser einordnen kann.

- U2: Als Nutzer:in möchte ich die Bewertung direkt am jeweiligen YouTube-Kommentar sehen, damit ich die Plattform für die Einordnung nicht verlassen muss.

- U3: Als Nutzer:in möchte ich, dass die Bewertung anhand mehrerer Merkmale erfolgt, damit nicht ein einzelnes Merkmal allein über die Einschätzung entscheidet.

- U4: Als Nutzer:in möchte ich, dass neu erfasste Kommentare in die Analyse einbezogen werden, damit während der Nutzung zusätzlicher Kontext berücksichtigt werden kann.

### SHOULD

- U5: Als Nutzer:in möchte ich nachvollziehen können, wie die Bewertung zustande kommt, damit ich die Einschätzung besser einordnen kann.

### COULD

- U6: Als Nutzer:in möchte ich zusätzliche Informationen zu den berücksichtigten Merkmalen anzeigen können, damit ich auffällign Eigenschaften eines Kommentars genauer untersuchen kann.

### WON'T

- U7: Als Nutzer:in möchte ich eine statistisch validierte Wahrscheinlichkeit erhalten, dass ein Kommentar von einem Bot stammt.
